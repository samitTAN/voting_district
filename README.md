# 自己的選區自己畫

## 專案緣起
翻閱[g0v database](https://docs.google.com/spreadsheets/d/1C9-g1pvkfqBJbfkjPB0gvfBbBxVlWYJj6tTVwaI5_x8/edit?gid=1563040282#gid=1563040282&fvid=1102076775g0v )時看到hackath13n | 台灣零時政府第拾參次無殼蝸牛黑客松 [自己的選區自己畫](https://www.youtube.com/watch?v=6tTFpZZLXb8&index=2&list=PLdwQWxpS513BhZaBy3VdW2MHQZd3ziulN)這個坑，跟當初的提案略有不同我想要做一個網站讓大家能夠參與「畫選區」這件事。

## 目前狀態
專案剛起步，尚在規劃與環境建置階段，還沒有實際功能。

## 開發環境設定
本專案使用 Python，建議以虛擬環境（venv）隔離套件安裝：

```bash
python3 -m venv venv
source venv/bin/activate  # Windows 請用 venv\Scripts\activate
```

`venv/` 目錄已加入 `.gitignore`，不會被版本控制追蹤，每位開發者請在本機自行建立。
